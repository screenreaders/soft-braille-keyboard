Soft Braille Keyboard - szybki przewodnik

Ten przewodnik jest dołączony do aplikacji, więc pozostaje dostępny nawet wtedy, gdy stare zewnętrzne linki przestaną działać.

1. Włącz klawiaturę

  1. Otwórz ekran główny aplikacji.
  2. Wybierz Włącz Soft Braille Keyboard.
  3. W ustawieniach metod wprowadzania Androida włącz tę klawiaturę.
  4. Wróć do aplikacji i wybierz Ustaw Soft Braille Keyboard jako klawiaturę domyślną.

2. Zacznij pisać

  • Użyj pola ćwiczeniowego na ekranie głównym, aby sprawdzić, czy klawiatura jest aktywna.
  • W Ustawieniach wybierz preferowaną tablicę brajlowską i stopień brajla.
  • Jeśli kalibrujesz układ dotykowy ręcznie, zapisz wynik przed normalnym używaniem klawiatury.

3. Monitory brajlowskie

  • Otwórz Diagnostykę monitorów brajlowskich, aby sprawdzić urządzenia Bluetooth lub USB.
  • Użyj eksportu diagnostyki, jeśli urządzenie łączy się, ale wysyła błędne polecenia albo powtarza wejście.
  • Jeśli treść ekranu ma pojawiać się na monitorze, włącz również usługę dostępności tej aplikacji.

4. Gdy coś nie działa

  • Jeśli wpisywany tekst się dubluje albo zachowuje się nietypowo, wyeksportuj diagnostykę i ślad IME z ekranu diagnostycznego.
  • Jeśli klawiatura się nie pojawia, sprawdź obie rzeczy: czy jest włączona i czy została wybrana jako domyślna.
  • Jeśli monitor brajlowski się nie łączy, sprawdź uprawnienie Bluetooth lub USB, a potem ponów próbę z poziomu diagnostyki.
