Soft Braille Keyboard Quick Start

This guide is bundled with the app so it remains available even when old external links disappear.

1. Enable the keyboard

  1. Open the main screen of the app.
  2. Activate Enable Soft Braille Keyboard.
  3. In Android input settings, enable the keyboard.
  4. Return to the app and activate Set Soft Braille Keyboard as the default keyboard.

2. Start typing

  • Use the practice text box on the main screen to confirm that the keyboard is active.
  • Choose the preferred braille table and grade in Settings.
  • If you manually calibrate the touch layout, save the result before regular use.

3. Braille displays

  • Open Braille display diagnostics to inspect Bluetooth or USB devices.
  • Use diagnostics export when a device connects but sends wrong commands or repeated input.
  • If screen content should appear on the display, also enable the app accessibility service.

4. If something goes wrong

  • If typed text duplicates or behaves unexpectedly, export diagnostics and IME trace from the diagnostics screen.
  • If the keyboard does not appear, verify both: keyboard enabled and keyboard selected as default.
  • If a braille display does not connect, check Bluetooth or USB permission and then retry from diagnostics.
